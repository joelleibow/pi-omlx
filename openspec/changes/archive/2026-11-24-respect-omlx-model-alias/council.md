| ID | Topic | Settled Ruling |

| R1 / R2 | Default recovery & wording | Keep Option 1 with no new startup warning. Replace "miss once" / "pick in `/model`": a folder-name default misses on every start until saved via `Ctrl+S` in `/model` or `settings.json`; `/model <alias>` and Enter switch only the session. `enabledModels` glob entries need the alias; non-glob `enabledModels` and `--model <folder>` still match the label when the label is the folder name. | R3 | Endpoint-scoped guarantees | Scope identity guarantees per endpoint. `/models/status` runs R6's rule and declines collisions to the folder name. `/models` fallback publishes the endpoint `id` verbatim (exact duplicates collapse to first; case-only differences publish as reported and trace). "Both endpoints publish one set of ids" covers models both endpoints list whose alias `/models/status` accepts. "No model is dropped" means the identity step drops only exact duplicate ids, first kept, as the parsers did before, so the refresh publishes, and the login probe counts, the same models as before. Record fallback residual risks in `design.md`. |
| R4 | Overlay lookup precedence | On `/models/status`, match overlay by exact directory name (`byModel[directoryName]`). On `/models` fallback, match in order: (1) exact overlay key equal to `/models` `id`, (2) unique overlay entry whose non-empty string `model_alias` equals the `/models` `id` byte-for-byte, (3) 2+ alias matches apply no overlay fields and trace competing keys, (4) 0 matches apply no overlay fields. No case-insensitive fallback. Matched entries apply the overlay's existing fields; on the fallback the matched key also becomes the directory name; never `id`. Record stale-overlay risk in `design.md`. |
| R5 | Display label (`name`) | Label precedence: (1) non-blank `display_name`, overlay's over server's, (2) directory name when known (status endpoint `id`, fallback alias-matched overlay key, or `/models` `id` when unaliased), (3) published `id`. Picker search by folder name holds only when the folder name is the label (`display_name` unset). |
| R6 | Status collision rule | On `/models/status`, publish an entry under its alias only if `model_alias` is set (R7) AND does not equal (ignoring case) any other parsed entry's endpoint `id` or `model_alias`. Otherwise publish under its endpoint `id` (directory name). Evaluated once across the full parsed status list (including hidden, profile, and limit-less entries) before overlay, global defaults, and `registrableModels`. |
| R7 | Set vs unset aliases | `model_alias` is unset only when absent, `null`, non-string, or `""`. Every other string (including whitespace-only and leading/trailing spaces) publishes verbatim when accepted under R6, on both paths. Add spec boundary note: Pi trims `/model <arg>`, so padded aliases filter the picker instead of switching, while `defaultModel` matches byte-for-byte. |
