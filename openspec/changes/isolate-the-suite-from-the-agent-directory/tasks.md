# Tasks

The design's decision-6 table is one unit test and nine runnable checks. Groups 2 to 4 need a poisoned operator home or a deleted assignment, which a vitest test cannot stage without touching the operator's machine, so each is a command run once and recorded. Every behavior task names its deletion, the change that makes it fail, so a reviewer can see the check is not one that stays green when the behavior goes. Record each run as the command, its exit code and the first line of its output.

A red run may omit the `PI_CODING_AGENT_DIR=<agent-dir>` prefix that `AGENTS.md` requires only when `HOME` points at a directory under this change's `.pi/marbleization/isolate-the-suite-from-the-agent-directory/` scratch area, or when the setup under test still assigns `PI_CODING_AGENT_DIR`; never with the operator's `HOME` and the variable unset.

In the evidence below, `<impl>` is `.pi/marbleization/isolate-the-suite-from-the-agent-directory/impl` in the working tree, which holds the scratch agent directory, the empty and poisoned homes, and the poisoned overlay the runs use.
