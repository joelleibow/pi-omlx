# Tasks

Every task names its spec scenarios (R1 to R5, numbered as `specs/credential-resolution/spec.md` orders them) and its design decision or step. Every `vitest` and `npm run check` command sets `PI_CODING_AGENT_DIR` to a scratch directory, so no run touches the operator's agent directory (Joel, "Tests never mutate operating functionality"). Tasks follow `design.md`'s six steps in order; nothing here decides what the design leaves open. No task is Joel's: the design names no observation only he can make.
